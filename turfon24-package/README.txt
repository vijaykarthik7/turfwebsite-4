TURFON24 — WEBSITE PREVIEW PACKAGE
====================================

WHAT'S IN HERE
--------------
index.html         The public-facing website (hero, why play here, turf
                    experience, gallery, facilities, pricing, booking flow,
                    contact, floating WhatsApp/chatbot widget).

admin.html          The admin dashboard (login, bookings, extended
                    enquiries, customers, calendar, reports, WhatsApp
                    enquiries, chatbot conversations, settings, profile).
                    Demo login: admin@turfon24.com / Admin@123

logo-assets/        The official client-provided logo files (horizontal
                    logo + tagline, and the logo mark alone), for use
                    anywhere outside these two HTML files.

HOW TO VIEW
-----------
Just open index.html or admin.html directly in any browser — double-click
the file, or right-click > Open With > your browser. No install, no
server, no build step. Both files are fully self-contained (all images
and the logo are embedded directly in the HTML), so they'll work exactly
the same offline as online.

WHAT THIS IS
------------
A static, front-end preview built to show the client what the site and
admin panel will look and feel like — real animations, real interactions
(the booking flow, the OTP steps, the chatbot, filtering, etc. all
actually work against sample data), but no live backend. Nothing typed
into a form here is actually saved anywhere or sent anywhere real yet.
